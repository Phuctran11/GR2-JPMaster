\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}
In the digital era, the demand for learning Japanese is rising rapidly, yet learners often face difficulties due to fragmented learning paths and a lack of intuitive contextual lookup tools. Current Learning Management Systems (LMS) predominantly focus on delivering static video lectures, lacking active vocabulary review features such as flashcards or smart AI assistants for real-time, personalized grammar explanations. To address these limitations, a comprehensive, all-in-one e-learning platform was developed, combining traditional LMS course management with intelligent interactive tools, including interactive flashcard reviews, a built-in popup dictionary, and an integrated Google Gemini AI learning assistant. This solution aims to optimize the learning experience, ensuring that students can study theory, look up vocabulary, and take mock exams seamlessly without having to switch between multiple applications.

The JPMaster system is developed based on a decoupled architecture comprising a frontend Single Page Application (React, Vite, Framer Motion) and a backend API (Express, TypeScript, PostgreSQL). It also integrates external services such as PayOS for automated payments and Cloudinary for media asset management. The main contribution of this report is the successful design and implementation of a closed-loop learning system: ranging from automatic course purchases via payment gateway integrations, detailed learning progress tracking, and smart vocabulary reviews, to taking standardized JLPT mock exams and receiving context-aware AI assistance. The final outcome is a fully functional software product that runs stably, passes automated and manual test cases, and is ready to effectively support Japanese language learners across all devices.
